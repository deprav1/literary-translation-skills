# Как улучшить Sol: малый тест

31 октября 2026. **Ни одна из трёх гипотез не прошла заранее установленный диагностический порог.** Минимальная редактура дала одно устойчивое локальное улучшение; расширение инструкций не дало устойчивого общего выигрыша.

## Что проверено

Восемь отрывков, 594 слова английского оригинала, три фантастических произведения двух авторов. Это ранее использованный development-материал. Обычный Sol-перевод получен заново; старые русские тексты не передавались. Проверены короткие производные инструкции из craft/QA, а не весь многоэтапный книжный процесс.

Один обычный перевод и три условия:

1. Перед ответом проверить агента, отрицание, модальность, время, направление и референты.
2. Перед ответом проверить голос, эмоциональную температуру, ритм, повтор и случайные кальки.
3. Отдельно отредактировать обычный черновик, меняя только доказуемые ошибки.

Каждое условие сравнивалось с обычным переводом в двух новых маскированных Sol-контекстах. Во втором A/B развёрнуты и порядок пар изменён. Это две модельные проверки, не два человека. Восемь источников остаются восемью источниками, а не 16 независимыми наблюдениями.

## Результат

В ячейках: победы / поражения / ничьи против обычного Sol; по восемь сравнений в каждой проверке.

| Добавление | Проверка 1 | Проверка 2 | Совпадающие победы / поражения | Порог сигнала |
|---|---|---|---|---|
| Смысловые связи | 3 / 3 / 2 | 5 / 1 / 2 | 2 / 1 | Не пройден |
| Голос и ритм | 2 / 2 / 4 | 6 / 1 / 1 | 2 / 1 | Не пройден |
| Минимальная редактура | 1 / 0 / 7 | 1 / 0 / 7 | 1 / 0 | Не пройден |

Для первых двух условий модельные предпочтения разошлись на пяти из восьми отрывков. Менялись порядок A/B, последовательность пар и сама сессия проверяющего: нельзя приписать разницу только позиционному смещению или только случайности модели. Обе совпадающие победы смысловой инструкции относятся к одному произведению. Слабый первый net и отсутствие выигрыша на разных произведениях не позволяют объявить этот метод улучшением.

### Что действительно изменилось в текстах

- **Редактор:** уточнил *kicked in his ribs*: обычное «вколачивала ему рёбра внутрь» стало «ударами ног вколачивала ему рёбра внутрь». Оба проверяющих предпочли уточнение; остальные семь текстов редактор сохранил буквально. Это одно локальное улучшение, а не подтверждение улучшения книг в целом.
- **Голос:** один проверяющий предложил крупное замечание. *If the estate found out … you'd be served …* стало «Если фонд узнавал … требование … приходило». Русский текст допускает чтение как реально повторявшиеся события вместо условной угрозы. Это модельное предложение о серьёзности, не заключение человеческого редактора; оно не скрыто за более благоприятным предпочтением второго проверяющего.
- **Самопроверки не гарантируют исправления:** оба проверяющих заметили в обычном тексте потерю явного указания на удары ногами; короткая смысловая инструкция сама по себе не получила устойчивого общего преимущества. Вторая проверка также нашла небольшое добавление «основную массу» вместо *a big mass* в обычном и отредактированном текстах. Отдельная редактура не устранила все замечания.

Списки замечаний обеих проверок сохранены полностью, включая расхождения. Цитаты сопоставлены с точными source/target; совпадение цитат доказывает наличие фразы, а не правильность литературной оценки.

## Токены, цена и кэш

Завершены шесть модельных вызовов: четыре генерации/редактирования и две проверки. Вход — **123 375 токенов**, выход, включая reasoning, — **10 835**. Полный измеренный API-эквивалент — **$0,3551**, ниже лимита $0,60. Объём входа включает служебный контекст CLI, а не только 594 слова перевода.

| Схема генерации на этих восьми отрывках | API-эквивалент | Против обычного перевода |
|---|---:|---:|
| Обычный Sol | $0,048136 | — |
| Sol + смысловая инструкция | $0,048838 | +1,5% |
| Sol + голос/ритм | $0,050434 | +4,8% |
| Sol + отдельная редактура | $0,101294 | +110,4% |

Последняя строка включает исходный перевод и редактора. Исследовательские проверки стоят отдельно $0,154534 и включены в общий $0,3551. Это локальные цены маленького пакета, не новая оценка стоимости книги.

Общий полезный английский префикс, схемы и рабочий каталог сохранены для повторного использования prompt cache. Однако **во всех шести usage cached input = 0 и cache writes = 0**. Причина нулевых попаданий через этот маршрут не установлена. Экономия от кэша не засчитана, искусственное дополнение промпта и дополнительные прогревочные вызовы не делались. Локально сохранённые результаты используются для всех повторных проверок без модельных вызовов.

Счётчик — Standard API-эквивалент по токенам: вход $2, cached $0,10, 30m cache write $2,50, выход $10 за миллион. [Официальные тарифы](https://developers.openai.com/api/docs/pricing), [правила prompt caching](https://developers.openai.com/api/docs/guides/prompt-caching). Это не счёт Codex, подтверждение backend model ID или service tier. Основная сессия, поиск и подготовка кода не входят в измеренный эксперимент.

Перед этими шестью фазами произошла одна неудачная попытка авторизации на прямом API: нет ответа перевода и turn.completed/usage, реальная стоимость не известна. После фиксации поправки использован уже настроенный владельцем локальный Responses provider с тем же запрошенным `gpt-6.1-sol`. Новые переводы не перегенерировались и не отбирались.

## Решение для процесса

**Не расширять обязательный промпт Sol и не включать полный повторный перевод ради небольшой правки.** Этот тест не оправдал таких изменений.

Полезный кандидат для следующего ограниченного теста — точечные исправления после замечаний с точными цитатами: модальность, агент, пропуск конкретного действия. Проверять отдельно пользу находок, цену и новые ошибки редактора; текущий опыт этого метода с выборочным запуском ещё не измеряет.

Книжный бриф, последовательность глав, накопленная терминология и человеческая редактура здесь не проверялись. Новые defaults, исходные skills и промосайт по этому screening не изменены. Все материалы отрывков сохраняют [атрибуцию и лицензию источников](../targeted-review-20261030/LICENSE.md).
