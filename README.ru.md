# Literary Translation Skills — мастерская перевода

**Открытые навыки для художественного перевода, независимой редакторской сверки и подготовки EPUB.**

[English](README.md) · [Установка](docs/INSTALL.md) · [Процесс работы](docs/WORKFLOW.md) · [Примеры](examples/README.md) · [Источники](docs/SOURCES.md)

## Попробовать вслепую

**[«Без лица» — три перевода, твой выбор, затем раскрытие авторства](https://deprav1.github.io/literary-translation-skills/).** База из 48 фрагментов, включая восемь современных отрывков Кори Доктороу (2006): каждый браузер получает свою детерминированную двадцатку. Без аккаунта и заранее назначенного победителя. [Методика, источники, лицензии текстов и данные](site/CONTENT.md). Это пилот читательского вкуса, не научный рейтинг.

Текущие AI-варианты заново получены в отдельных сессиях Sol с одинаковым английским контекстом: короткий запрос, планируемый craft и craft после QA-редактуры. [Запись запуска](site/research/fresh-v5/record.json) показывает реальные этапы. Исторические переводы генераторам не передавались; возможное знание этих текстов из обучения модели не исключено.

Это набор инструкций `SKILL.md` для AI-агентов. Он помогает удерживать авторский голос, логику сцены и точность перевода, а затем выпускать проверяемую электронную книгу. Это не сервис автоматического перевода и не библиотека чужих книг.

## Быстрый старт

Посмотреть доступные навыки:

```sh
npx skills add deprav1/literary-translation-skills --list
```

Установить основные навыки в текущий проект Codex:

```sh
npx skills add deprav1/literary-translation-skills --agent codex --skill literary-translation-craft --skill literary-translation-qa --skill literary-translation-evaluation --skill epub-translation-production
```

Для пользовательской установки добавить `--global`. Альтернативы: встроенный installer Codex или ручное копирование папок. Команды для PowerShell и других систем — в [инструкции](docs/INSTALL.md).

Пример запроса после установки:

```text
Используй $literary-translation-qa.
Сравни эти два абзаца с оригиналом: смысл, фокализация, ритм и естественность русского.
Раздели ошибки, спорные чтения и вкусовые предложения. Не переписывай книгу автоматически.
```

## Какие навыки входят

| Навык | Задача |
|---|---|
| [literary-translation-craft](skills/literary-translation-craft/SKILL.md) | Художественный перевод, голос повествователя и персонажей, ритм, неоднозначность, повторы |
| [literary-translation-qa](skills/literary-translation-qa/SKILL.md) | Независимая сверка и отдельное решение по каждой предложенной правке |
| [literary-translation-evaluation](skills/literary-translation-evaluation/SKILL.md) | Сравнение вариантов, слепой выбор, контрольные ошибки и компактная шкала с ограничениями |
| [epub-translation-production](skills/epub-translation-production/SKILL.md) | Сборка точной редакции, ссылки, примечания, курсив, адаптивная вёрстка и границы TTS-проверки |
| [amatka-literary-ru](skills/amatka-literary-ru/SKILL.md) | Необязательный профиль «Аматки»: называние как действие, сдержанный голос, предметные повторы |
| [ngai-gimmick-ru](skills/ngai-gimmick-ru/SKILL.md) | Необязательный профиль Сианн Нгай: эстетическая и марксистская терминология |
| [blank-space-ru-translation](skills/blank-space-ru-translation/SKILL.md) | Необязательный профиль W. David Marx: культурная история, ирония и логика аргумента |

Общие навыки не привязаны к одному исходному языку. Книжные профили ориентированы на русский перевод и содержат рабочие решения, а не официальный перевод или полный текст произведений.

## Принципы

1. **Масштаб соответствует запросу.** Проверка двух абзацев не превращается в аудит всего романа.
2. **Естественность и точность проверяются раздельно.** Гладкий пересказ может быть неверным, буквальная калька — тоже.
3. **Литературные трансформации допустимы.** Перестройка синтаксиса и образа оценивается по функции и эффекту, а не по словарному совпадению.
4. **Рецензент не принимает решения за редактора.** Уверенность модели и совпавшая цитата не разрешают автозамену.
5. **История изданий сохраняется.** Новый EPUB получает отдельный путь и контрольную сумму; дизайн не подменяет актуальный текст старой версией.
6. **Проверки говорят только о том, что доказано.** EPUBCheck не оценивает прозу, а скриншот браузера не подтверждает работу озвучки во всех ридерах.

## Что можно делать

- Перевести сцену по короткому брифу с сохранением голосов и точки зрения.
- Разобрать перевод по смыслу, стилю, логике, именам и повторяющимся формулам.
- Сохранить обоснованные решения `accept/edit/reject/defer` с точными версиями до и после.
- Подготовить EPUB с проверкой текста, разметки, навигации, ссылок и оформления на узком/широком экране.
- Вести большой перевод с понятными checkpoint и непересекающимися областями работы.

## Проверка проекта

Нужен Python 3.10+, сторонние Python-пакеты не требуются:

```sh
python scripts/validate.py
python -m unittest discover -s tests -v
```

Проверяются структура навыков, ссылки, переносимость и отсутствие случайных личных материалов. Это проверка пакета, а не литературный экзамен модели.

## Terra и Luna для экономии

В [новом диагностическом пилоте](evals/budget-translation-20261030/RESULTS.md) Terra/Luna переводят с английского, без Sol-черновика. Бриф дал предварительный выигрыш Terra, но не окупился на этой выборке; проверенные добавки Luna чаще ухудшали результат. Полные маршруты с проверкой дали около 26% и 20% экономии и не прошли порог качества. Аудит теперь учитывает планирование, проверки, эскалации и сохранённые ошибки. `python scripts/validate_budget_trial.py` воспроизводит учёт по артефактам. Это модельная диагностическая оценка, не человеческое литературное принятие.

[Повтор в новых сессиях](evals/budget-translation-20261030/replication-2/RESULTS.md) показывает оба прогона рядом: те же 30 исходных отрывков, новый порядок аудита, без выбора лучших ответов и изменения настроек перевода по умолчанию.

## Проверка новых навыков

В [предварительно зафиксированном опыте](evals/targeted-review-20261030/RESULTS.md) проверены три кандидата: 36 диагностических случаев и 30 новых отрывков, равный бюджет редакторских вызовов и скрытые методы. Ни один не прошёл порог внедрения; действующие skills сохранены. `python scripts/validate_targeted_trial.py` воспроизводит проверку артефактов и допуска. Это модельная оценка, не человеческая литературная валидация.

## Ограничения и лицензия

Проект не обещает идеального перевода, не заменяет профессионального редактора и не гарантирует универсальный TTS. Аудиофайлы не генерируются. Озвучка в конкретном ридере считается проверенной только после отдельного испытания.

Инструкции, шаблоны, синтетические примеры и код распространяются по [MIT](LICENSE). Современные отрывки Доктороу и производные переводы — **CC BY-NC-SA 2.5**, не MIT; у классических текстов отдельные условия. См. [лицензии текстов](site/CONTENT.md). Права на книги и сторонние руководства остаются у их правообладателей. Личные архивы, полные книги, внутренние отчёты и API-ключи в репозиторий не входят.

Чтобы предложить улучшение, прочитай [CONTRIBUTING.md](CONTRIBUTING.md) или создай issue с небольшим синтетическим либо разрешённым примером.
