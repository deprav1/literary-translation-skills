# New skill search for lower-cost translators

Read the [machine-readable search record](search.json) for current repository metadata and adoption boundaries. The useful new candidates are mechanisms, not a verified universal literary skill:

- [Tencent Hy-MT2 skill](https://clawhub.ai/tencent-adm/skills/hy-mt2-translator-skill): concrete terminology/style/context interfaces. Its backend changes the model, so it is not installed for a Terra/Luna experiment.
- [EN→RU terminology retrieval](https://aclanthology.org/2026.wmt-main.40/): source-linked terms by domain/sense; specialised domains rather than literary quality.
- [MAPS](https://aclanthology.org/2024.tacl-1.13/): preparatory translation knowledge followed by selection; use a compact handoff instead of repeating a large whole-book prompt.
- [Chain-of-Dictionary](https://aclanthology.org/2024.emnlp-main.55/): optional lexical evidence; the released proof does not establish EN→RU fiction improvements on these models.

The pilot tests original compact profiles inspired by these operations; it does not copy their bundles or implement all stages of their research systems. Stars measure visibility, not translation quality. Versions and counts are dated in search.json.
