# Исправление маршрута до первого ответа модели

Первый логический вызов `plain` не получил перевода: прямой API вернул 401, CLI завершился без output и turn.completed. Внутренние сетевые reconnect CLI не являются новыми полученными переводами. Сырой журнал сохранён вне публичного репозитория.

Причина: `--ignore-user-config` отключает также настроенный владельцем локальный provider. Проверка его `/models` с настроенными реквизитами успешна; запрошенный `gpt-6.1-sol` присутствует.

Перед первым полученным переводом добавлен адаптер подключения. Он сохраняет исходный runner и его preregistration, источники, инструкции, schemas, medium, изоляцию, общий prefix, критерии и денежный лимит. Используется только уже настроенный локальный Responses provider; секреты передаются через окружение дочернего процесса, не записываются в репозиторий, промпт или аргументы CLI. WebSockets отключён для этого транспорта.

Разрешены шесть завершённых модельных фаз плюс одна уже случившаяся неудачная попытка авторизации без ответа и без опубликованного usage. Реальный расход неудачной попытки неизвестен; нулевая стоимость не утверждается. Никаких сравненных/отброшенных переводов ещё не было. Последующие ошибки снова останавливают опыт; генеративных повторов нет.

Адаптер и запись сбоя фиксируются отдельно до запуска. В итогах нужно указать маршрут и не выдавать CLI usage за подтверждение реального счёта, server-side настроек кэша или фактического backend model ID.
