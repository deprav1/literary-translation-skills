# Sol: малый тест трёх гипотез

31 октября 2026. Диагностический screening; не доказательство эффективности.

## До генераций

- Восемь заранее выбранных английских отрывков из прежнего development-набора: 594 слова, три произведения, два автора. Выбор по английским механизмам: перспектива, детская речь, разговорный регистр, образы, метафора, ирония, онтологическая неоднозначность, пространственная логика. Русские ответы прошлых опытов не используются.
- Один Sol `gpt-6.1-sol`, medium, свежие изолированные сессии без инструментов и истории. Первые ответы сохраняются, повторов и best-of нет.
- Четыре условия: обычный перевод; короткая скрытая проверка смысловых связей; короткая проверка голоса и ритма; один отдельный консервативный редакторский проход по обычному переводу. Последнее — двухвызовная схема, её цена включает исходный перевод.
- Фиксированный общий английский префикс, одинаковый рабочий каталог и схемы переводчика. Меняется суффикс задания. Кэш не используется для передачи русских ответов между первыми переводами. Только редактор получает обычный черновик.
- Две новые модельные проверки всех 24 пар против обычного перевода. Во второй A/B меняются местами, порядок пар меняется. Методы скрыты. В каждой проверке сначала предпочтения, затем смысловые замечания; никакое замечание не удаляет пару. Повторный Sol не является независимой человеческой панелью.
- Для положительного диагностического сигнала: обе проверки имеют net ≥ 2, совпадающих побед ≥ 2 на разных произведениях, совпадающих поражений ≤ 1, нет новых крупных/критических замечаний ни у одного проверяющего; все ID и точные цитаты проходят проверку. Это консервативное исследовательское правило, не статистическое подтверждение. Несогласие проверяющих отдельно. Ошибки модели-проверяющего остаются предложенными, человеческого принятия нет.
- Максимум шесть вызовов, 200 000 входных и 12 000 выходных токенов. Остановка между вызовами при исчерпании лимита либо недостаточном остатке $0,60 API-эквивалента; для следующего вызова резервируется $0,14. Серверный расход отдельного вызова заранее не гарантирован. Тайм-аут 180 секунд; ошибка останавливает опыт без повторов.
- Отчёт сохраняет фактический `cached_input_tokens`, cache writes, холодную цену и цену с наблюдаемым кэшем. Запись кэша оплачивается вместо обычного входа, не дополнительно. Скрытый CLI-контекст тоже входит в usage. Тарифы Standard: вход $2, cached $0,10, запись 30m $2,50, выход $10 за миллион токенов. CLI не подтверждает реальный счёт или service tier. Стоимость основной сессии и поиска не включена.

Общие токены полезного контекста используются без искусственного padding. Нулевой hit не скрывается и не вызывает повторов для прогрева.
