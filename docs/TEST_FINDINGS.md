Сайт — пилот читательского предпочтения фиксированных текстов, не доказательство эффекта отдельного skill. Разные числа вызовов, контекст и транспорты ограничивают причинные выводы. Повторения одной выборки не становятся новыми независимыми книгами. Модельные роли не являются человеческой редакторской панелью.

## Изменения в устанавливаемых пакетах

- **Craft:** компактный контекст по текущей сцене; source-linked замечание перед дополнительной генерацией; локальная правка поддержанного дефекта; отсутствие обязательной полировки исправного текста. Книжный бриф и литературное чтение сохранены по масштабу задачи.
- **QA:** точные `source_quote`, `target_quote`, replacement и решение редактора; отдельные стадии discovery, adjudication и application. Новая утилита применяет принятые исправления по исходному hash и уникальному anchor, запрещает пересекающиеся правки и нарушение объявленных protected tokens. Неизменённые блоки сохраняются буквально.
- **Evaluation:** различаются свежий поиск ошибок и редактура с известными подсказками. Учёт включает полную схему, исторические расходы и фактический кэш; общий prefix или requested cache flag не считаются скидкой сами по себе.

Короткому запросу не навязываются JSON, hash, файл или книжный цикл. Утилита нужна для повторяемого применения локальных исправлений в файловой работе и полностью помещается в QA-пакет. Серьёзная стилистическая или структурная редактура допускается в рамках пользовательского запроса и требует чтения большего фрагмента.

## Что проверено после внедрения

Новый устанавливаемый helper воспроизводит ровно те же два исправления из guided-опыта без новых модельных вызовов; остальные шесть текстов совпадают с draft. Отдельные тесты проверяют stale hash, неверные цитаты/ID, повторяющиеся и пересекающиеся anchors, deferred-решения, удаление добавления, protected tokens и работу вне репозитория. После механического применения литературная проверка остаётся незавершённой до фактического чтения.

Это воспроизведение поддержанного изменения и проверка инженерных ограничений. Полный обновлённый пакет не проходил новый литературный A/B-тест: улучшение произвольных книг и эффективность автономного аудита не доказаны.

## Что не активировано

Нет нового model default, длинного общего checklist, обязательных memory-примеров, каскада дешёвых моделей или дополнительных полных аудитов без конкретного риска. Старые переводы, голоса сайта и замороженные результаты опытов не изменены.

```sh
python scripts/validate.py
python -m unittest discover -s tests -v
```
