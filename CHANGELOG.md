# Changelog

## 0.3.0 — 2026-10-30

- Added traceable execution stages, source/translation boundary checks, and conflict resolution for literary editing.
- Added standalone comparison-design guidance on isolated generation, reference exposure, skipped votes and versioned results.
- Improved the reading interface with passage navigation, skipping without a vote, reading controls, and results grouped by generation conditions.

## 0.2.0 — 2026-10-29

- Added `literary-translation-evaluation`: a standalone, context-first evaluation skill with hard gates, blind pairwise review, compact dimensions, and explicit limits.
- Added a source-backed evaluation/discovery note without bundling third-party skill files or book material.
- Inspected popular translation implementations; added compact context handoffs, glossary sense/alias decisions, and conditional Russian editing checks to the craft skill.
- Kept automated assessments distinct from professional human acceptance and preference collection distinct from diagnostic filtering.

## 0.1.0 — 2026-10-29

- Three general skills for literary craft, independent review, and EPUB production.
- Three optional Russian-language book profiles.
- English and Russian documentation, installation recipes, and synthetic examples.
- Standalone reference templates and Codex picker metadata.
- Standard-library validation, behavior tests, and GitHub Actions CI.

Initial public release. No translation-quality benchmark or universal reader/TTS compatibility is claimed.
