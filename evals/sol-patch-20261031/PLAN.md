# Sol: аудит с цитатами и точечные замены

31 октября 2026. Малый development-тест; не подтверждение качества книг.

## Метод до получения ответов

Используется сохранённый обычный Sol-черновик восьми отрывков (594 слова), без новой генерации. Источники и черновик те же, что в [предыдущем опыте](../sol-micro-20261031/RESULTS.md). Старые замечания, предпочтения и другие переводы новому аудитору не передаются.

1. Свежий Sol-аудит всех восьми пар: смысл, агент, отрицание, модальность, добавления/пропуски и явно сломанный русский. Только точные цитаты, без стилистических пожеланий; максимум одна находка на отрывок.
2. Новый Sol рассматривает каждую находку: принять, отвергнуть или оставить неопределённой. Принятие возвращает одну точную замену русского span. Код проверяет уникальность anchor и собирает результат без перегенерации абзаца. Остальной текст сохраняется буквально.
3. Две новые маскированные проверки patched против исходного текста, с разворотом A/B и иной последовательностью пар. Каждая читает все восемь пар, включая совпадающие; совпадающие тексты обязаны получить tie. Предпочтения и смысловые замечания сохраняются отдельно. Предложенные ошибки не считаются человеческим заключением.

Все вызовы запрашивают `gpt-6.1-sol`, medium, отдельными Responses-запросами без истории, инструментов и внешнего поиска, через уже настроенный владельцем локальный provider. Responses API вместо CLI меняет транспорт/служебный контекст: это тест всей схемы, не чистая оценка отдельной инструкции. Фактический backend и реальный счёт шлюза не гарантируются.

Общий первый content block содержит только английский источник и контекст; в нём explicit cache breakpoint, TTL 30m. Меняющиеся задача и русские кандидаты находятся после границы. Никаких padding или прогревочных вызовов. Кэш и его цена учитываются только по полученному usage. Секреты берутся из уже настроенного подключения в памяти и не публикуются.

Предел: четыре вызова, суммарно 50 000 input и 8 000 output tokens; API-эквивалент $0,25. `max_output_tokens`: 1800 аудит, 1500 редактор, 2200 каждая проверка. Перед следующим вызовом резервируется его полный output и 15 000 input по консервативной цене записи кэша. Каждый запрос имеет timeout 180s. Первый ответ сохраняется, повторов/выбора лучшего нет; отказ API останавливает опыт. Если нет находок или все правки отвергнуты, ненужные последующие вызовы пропускаются и сигнал не объявляется.

Тарифы Standard за миллион: input $2, cached $0,10, cache write 30m $2,50, 12h $5, output $10. Reasoning уже в output. Долгие TTL не запрашиваются, но lifetime-компоненты usage учитываются, если возвращены. Отсутствие usage не означает нулевую стоимость. Общая цена включает audit, editor и обе исследовательские проверки; отдельно — marginal production audit+editor и историческая стоимость переиспользованного черновика. Основная переписка и подготовка кода исключены.

## Решение

Для диагностического сигнала нужны net ≥ 2 в каждой проверке, минимум две совпадающие победы на разных произведениях, не больше одного совпадающего поражения, отсутствие новых major/critical замечаний, точность всех цитат/ID и отсутствие правок вне принятых span. Отклонение находится и публикуется, а не исправляется новой генерацией. Совпадение проверок не является человеческой независимой валидацией.

Даже положительный результат здесь — кандидат для новых произведений и двуязычного редактора. Defaults и промосайт не меняются. Производные переводы и оценки сохраняют [права и атрибуцию источников](../targeted-review-20261030/LICENSE.md).
